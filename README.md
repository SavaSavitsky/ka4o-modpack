# Ka4o Adventures

Збірка Minecraft Java 1.21.1 / NeoForge для гри з друзями.

## Встановлення

1. Відкрий розділ **Releases** цього репозиторію.
2. Завантаж **LauncherSetup.exe** з останнього релізу та встанови лаунчер.
3. Укажи власний нік у профілі.
4. У вкладці **Модпак** увімкни збірку, потім натисни **Грати**.

Лаунчер завантажує Minecraft, Java та моди й перевіряє контрольні суми.
Для першого встановлення та оновлення потрібен інтернет.

## Що входить до збірки

Create, Ars Nouveau, L_Ender's Cataclysm, When Dungeons Arise,
Tom's Simple Storage, JEI, Sophisticated Backpacks, Waystones, Jade,
Xaero's Minimap, Xaero's World Map, Farmer's Delight, Lootr,
Iron's Spells 'n Spellbooks та Applied Energistics 2, а також потрібні бібліотеки.

Точні версії, авторські сторінки, ліцензії та адреси завантаження наведено
у `ka4o-adventures.json`. JAR-файли модів завантажуються з Modrinth;
цей репозиторій їх не зберігає.
